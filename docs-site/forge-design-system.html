ⓘ Note
Options defined with required: true will cause a validation error if not provided on the command line or via configuration.
✨ Tip
Use the TestHarness to validate your CLI's behavior without spawning subprocesses. It's significantly faster and gives you direct access to parsed arguments.
⚠ Warning
The coerce function runs after type parsing but before validation. Ensure your coerced value still passes any choices constraints.

13. Prose Content

How rendered markdown documentation looks within the forge theme.

Middleware Pipeline

Middleware functions transform parsed arguments before your handler executes. They're applied in registration order and can add, modify, or validate args.

Each middleware receives the current args and returns a new args object. The type system tracks these transformations, so your handler always sees the final shape.

Adding Middleware

Use the .middleware() method to register a transform:

Middleware is powerful but should be used sparingly. For simple validation, prefer the built-in validate option instead.
  • Middleware runs once per command level during discovery
  • Deduplication by reference prevents double-execution
  • Init hooks see middleware-transformed args

Execution Order

  1. Parse options (non-strict)
  2. Run middleware transforms
  3. Execute init hooks
  4. Discover subcommands

Ambient Effects

• Rising embers — Subtle orange particles drift upward from the bottom of the viewport. Always-on but very faint (6-10 particles, low opacity).

• Heat shimmer — Applied to hero text. A translucent warm overlay sways left-right to simulate heat distortion above the "forge."

• All effects respect prefers-reduced-motion.
