interface PromptProvider

A prompt provider that can fulfill missing option values interactively.

Properties

NameTypeDescription
filter?(name: string, config: InternalOptionConfig) => booleanIf provided, this provider only handles options where filter returns true. Providers without filters act as fallbacks.
prompt?(option: PromptOption) => Promise<unknown>Prompt for a single option. Called per-option if promptBatch is not defined.
promptBatch?(options: PromptOption[]) => Promise<Record<string, unknown>>Prompt for multiple options at once. Preferred over prompt when available.
